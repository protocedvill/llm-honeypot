# Contributing

This is a research/portfolio project, not a maintained product, but issues
and pull requests are welcome.

- Found a bug or have an idea? Open an issue first, especially for anything
  non-trivial — it's a cheap way to align before you spend time on a PR.
- Small, focused PRs (typo fixes, doc corrections, a contained bug fix) are
  fine to send directly.
- Run `pytest` before opening a PR; CI runs it too, but a red PR slows things
  down for everyone.

There's no formal process beyond that.
