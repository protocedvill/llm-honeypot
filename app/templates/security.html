Security & Compliance

Payment and student verification data are some of the most sensitive data a company can hold. We build and audit our infrastructure accordingly.

SOC 2 Type II
GDPR Compliant
PCI DSS (via processor)
99.95% Uptime SLA

Encryption

All data is encrypted at rest using AES-256 and in transit using TLS 1.2+. Database backups are encrypted with a separate key set, rotated quarterly.

Access controls

Production access is limited to a small on-call engineering group, gated by single sign-on and hardware security keys. All production access is logged and reviewed monthly.
